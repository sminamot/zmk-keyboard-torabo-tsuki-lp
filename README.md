
[torabo-tsuki LP](https://github.com/sekigon-gonnoc/torabo-tsuki-lp)用のZMKファームウェア

* _centralがついているuf2をトラックボールがついている方に、_peripheralを反対側に書き込んでください
* Mサイズ向けの構成です
* キーマップは`config/keymap.keymap`で管理します
* ZMK Studioはビルド要件のため有効です。キーマップは`config/keymap.keymap`を正として管理し、変更後はGitHub Actionsで生成されたUF2を左右に書き込んでください
